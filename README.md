# Amazon Homepage Clone

A pixel-focused front-end recreation of the Amazon.com homepage, built from scratch with **HTML, CSS, and JavaScript**, no libraries, just fundamentals.

## What's included

- Sticky top navigation bar with logo, search bar + category dropdown, delivery location, account/orders, and cart icon
- Secondary nav bar with category links
- Hero image carousel/banner section
- Grid of product/category cards, styled to match Amazon's card layout
- "Sign in for the best experience" style prompt section
- Multi-column footer with "Back to top" and link groups
- Fully responsive layout

## Tech Stack

- **HTML5** – semantic structure
- **CSS3** – Flexbox/Grid for layout, custom styling to match Amazon's visual language
- **JavaScript** – interactivity (e.g. carousel behavior, dropdowns, etc.)

## Why I built this

I wanted to sharpen my CSS layout skills by recreating a real, complex, high-traffic UI instead of a tutorial project. Amazon's homepage is a great challenge because of its dense grid system, nested components, and attention to spacing/alignment - replicating it forced me to actually think like a front-end developer solving real layout problems, not just follow along with a video.

## What I learned / practiced

- Structuring a large page into reusable, organized components
- Matching real-world spacing, typography, and color systems precisely
- Building a responsive navbar and search UI
- Working with CSS Grid/Flexbox for complex, multi-section layouts
- Writing clean, readable HTML/CSS without a framework as a crutch
